## Result

Added `modelanvil.smollm2-gpu-sft.v1`, separate from the existing CPU character and general-transformer references. It verifies one immutable SmolLM2-135M snapshot, encodes the published protected train split with its actual tokenizer and performs FP32 AdamW updates on an explicitly selected GPU. Job placement pins the worker, device/backend, model/tokenizer/dataset hashes, recipe, packages and runtime build. Preflight reports GPU requirements and explicitly unknown duration/money; launch and worker execution revalidate the resources.

Checkpoint state stores checksummed local Safetensors weight and Adam-moment artifact references, committed through live lease/fence/cancellation checks. It restores optimizer moments and cursor, rejects non-finite/unmaterialized tensors and produces a candidate through existing step-budget accounting. Local loaders prohibit pickle and remote code. A real reload check found generic Safetensors serialization retained the wrong tied embedding alias; checkpoint writing now uses Hugging Face's model serializer, and both independent inference and exact recovery passed afterward.

Changed paths: `modelanvil/runners/training/hf_runtime.py`, `test_hf_runtime.py`, `registry.py`, `hardware.py`, `preflight_report.py`, `test_transformer_evidence.py`; `modelanvil/runners/management/commands/setup_gpu_training.py`; `modelanvil/api/views/training_views.py`; `modelanvil/runners/evidence.py`; `requirements.gpu.txt`; `scripts/hf_candidate_infer.py`, `scripts/qualify_hf_gpu.py`; capability/status/setup documentation.
