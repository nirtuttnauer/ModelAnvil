## Measured quantization comparison

[Raw sequential measurements](quantization-report.json) and [summary](measurement-summary.json) compare the same LoRA-merged model as unquantized F16 GGUF and actual Q8_0 GGUF. Both have real tensor payloads. Native quantizer/source revision is `f5027fb21307eb264aed483242603d68c87b0fe3`; Q8_0 tensor types and native decoded outputs are retained separately from structural validation.

| Observation | F16 baseline | Q8_0 |
| --- | ---: | ---: |
| Weight bytes | 270,885,376 | 144,810,496 |
| WikiText perplexity | 27.1527 | 27.1308 |
| Median cold-process generation wall time, three repetitions | 0.182967 s | 0.129106 s |
| Maximum native generation-process peak RSS | 307,904,512 bytes | 323,878,912 bytes |

The weight file is about 46.5% smaller. Peak resident memory was higher in this observation; no RAM saving is claimed. Wall time includes startup/loading and bounded generation of at most 16 tokens. Each sample runs in a fresh wrapper with one native child, avoiding cumulative parent/previous-child RSS. One native thread and no GPU offload were selected. Other host workloads were present, OS file caches were not flushed, and three repetitions do not establish a general latency/throughput guarantee.

The [held-out manifest](heldout-manifest.json) identifies the official Salesforce/wikitext `wikitext-2-raw-v1` test shard at revision `b08601e04326c79dfdd32d625aee71d232d685c3`, its exact source checksum, license metadata and the first 32,000 Unicode characters of concatenated test rows. Eight 128-token chunks were evaluated per format. The fixed 5% perplexity regression check passed, with a measured relative change of approximately -0.0807%. The final admission guard pins the exact public shard and selected-text hashes; a nonfixture flag alone cannot qualify another corpus. These fine-tuning runs never consumed this test text. Its inclusion in base pretraining is unknown. No domain/customer quality or production gate passed. The earlier MLX 4-bit validation failure remains a failure for its own format/device.
