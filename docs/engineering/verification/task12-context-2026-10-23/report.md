# TASK-12 bounded measured Context Lab

23 October 2026. Context Lab now authors arbitrary ordered blocks, roles, types and retention priorities and saves changes as new immutable API revisions. A recipe can pin an accessible committed CPU character or general-transformer reference model. Its weight checksum, tokenizer specification, runtime contract and exact role-lines template are frozen; compilation and execution verify them again. New recipes, versions and experiments inherit the active project. Existing tenant-wide rows retain their legacy scope.

Pinned compilation invokes the runtime's actual character/byte encoder, including BOS/EOS and template text, and budgets the exact serialized model input plus output reserve. Overflow either fails or removes lower-priority blocks, reporting actual omitted token differences. Priority-one blocks cannot silently disappear. Per-block limits and omissions remain inspectable. Unpinned recipes retain the deterministic estimator with explicit labels. Unsupported automatic summarization stays unavailable.

The measured action runs both selected recipes on the same frozen cases and pinned CPU model/tokenizer/template/output reserve. It executes greedy model inference, records seeds and environment, and stores each exact prompt, actual output, elapsed time, usage, evidence-marker retention, omissions, truncations and failures. Exact-match fractions include failed cases in the denominator and expose completion coverage. Experiments are bounded to eight cases and the shipped CPU reference context/output envelopes (at most 64 context and 32 generated tokens). This is a small local reference workflow; it does not qualify general language-model quality, GPU performance or resistance to malicious instructions.

Each case supplies independent memory and frozen tool text. Optional API memory fixtures retain only matching-session, nonexpired entries; they cannot be mixed with an unfiltered raw memory override. No session state or live tool invocation transfers between cases. Saved reports freeze inputs and recipe digests; current access, changed recipes, tokenizer/template/weight pins and tombstones are rechecked on read. Unavailable inputs withhold results. Generic experiment writes are closed so clients cannot submit fabricated measured evidence; the measured action is the supported writer. Viewer compilation/read access does not permit inference execution.
