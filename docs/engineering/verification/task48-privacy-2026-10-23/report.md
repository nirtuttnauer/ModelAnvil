# Private data policy verification, 23 October 2026

The reconciled implementation preserves main's native-template evaluation and account-recovery behavior. It adds project acquisition/offline restrictions, content-free diagnostics, explicit interaction-measurement retention and purge controls, safe default application/request logging, current-access checks for saved comparisons and retrieval engines, and project ownership for newly created knowledge bases.

The guarded Hugging Face client uses the pinned 1.x SDK's HTTPX factory. Every request and redirect checks the current policy, rejects content uploads and absent workspace/provisioning scope, strips cookies, disables ambient proxy/netrc configuration, and strips credentials on cross-origin redirects. The separate resumable download transport retains Requests under the same restrictions. Native Xet transfer and Hub telemetry are disabled. These are controls on shipped transports, not an OS firewall or sandbox for arbitrary trusted plugins.

## Observations

- Eight privacy tests pass with optional transports installed; five run on the base-only install and three transport checks skip because those packages are absent. Tests cover administrator/project restrictions, destination revocation, redirects and credential stripping on both transports, offline refusal before transport, lost scope, safe logs/request IDs, content-free diagnostics, scoped retention deletion and revoked cached retrieval.
- The combined privacy/model-workspace/RAG suite passes 35 tests. A focused saved-comparison test additionally verifies that a revoked model grant hides the saved comparison and refuses replay. Existing cross-project artifact, annotation and feedback controls remain covered by the full backend suite: 922 tests passed with five optional skips.
- The [offline CPU observation](offline-baseline.json) executes real optimization, durable candidate/baseline evaluation, authenticated inference and an explicit reject decision while Python socket connects and create_connection are refused. It observed zero outbound connection attempts. This uses provisioned local reference weights and does not qualify GPU hardware or production deployment.
- The [browser observation](browser-checks.json) saves offline policy, reloads it, verifies another project's independent policy, and downloads diagnostics containing only the declared fixed fields. Screenshots at 1440 and 390 pixels were inspected; no page errors or horizontal page overflow were observed. Frontend tests and production build pass.

No private session cookies, worker credentials, raw logs, model weights, database or private artifact storage are included. The report does not add an external analytics sink or content-collection mode. Legacy knowledge bases with no project retain their prior tenant-shared ownership; operators must review them before a private-project rollout. Remote workers, databases, brokers, stores, backups and reverse proxies require their separate deployment and residency controls. Current GPU execution remains unqualified after the dependency upgrade.
