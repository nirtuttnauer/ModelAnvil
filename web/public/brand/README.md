# ModelAnvil logo assets

Refined from the approved orange interlocking-symbol concept. The mark uses three
identical segments rotated by 120 degrees, with open gaps and a hexagonal center.
All SVGs are self-contained: flat fills, actual vector paths, and no embedded
images, external resources, or font dependencies.

| File | Use |
| --- | --- |
| `modelanvil-logo.svg` | Orange symbol and charcoal wordmark on a transparent background; use on light surfaces. |
| `modelanvil-icon.svg` | Standalone orange symbol on a transparent background. |
| `modelanvil-logo-dark.svg` | Lighter orange symbol and warm-white wordmark on a solid charcoal background. |
| `modelanvil-logo-reversed.svg` | The dark-surface logo with a transparent background. |

Light symbol: `#D65A31`. Dark-surface symbol: `#ED8057`.
Charcoal: `#24272B`. Dark canvas: `#181B1F`. Warm white: `#FAF9F6`.

Preserve the viewBox proportions and internal clear space. Use the icon at 24 px
or larger for clear segment separation; 16 px was checked as a compact fallback.
Use the horizontal logo at 180 px or wider. For web usage, load the appropriate
asset with an image element and descriptive alt text, such as `alt="ModelAnvil"`.

The outlined wordmark uses Outfit at weight 650 with adjusted letter spacing.
Outfit is distributed under the SIL Open Font License; see `Outfit-OFL.txt` and
the [font source](https://github.com/google/fonts/tree/main/ofl/outfit).
Font files are not required to use these SVGs.
